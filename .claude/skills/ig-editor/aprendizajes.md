# Aprendizajes de edición (Clipardo)

Registro de cada corrección que hace el usuario sobre la edición. **Leelo antes de renderizar** y aplicá todas las reglas vigentes.

Cómo se usa:
1. Cada vez que el usuario corrige algo de un Reel (o aprueba un cambio que propusiste), agregá una fila abajo **en el momento**, sin esperar a que lo pida.
2. Si la corrección se puede automatizar, pasala a `config.json` o a `igeditor.py` y anotá dónde quedó en la columna "Aplicado en". Si no se puede (es criterio), queda como regla para revisar a mano en el Paso 3.
3. Si una corrección nueva contradice una vieja, marcá la vieja como ~~tachada~~ y aclarás cuál la reemplaza.
4. Cuando una regla se repite 3 veces, subila a la sección "Reglas firmes".

## Reglas firmes

- El texto (hook, portada, crédito) **nunca tapa una cara**. Se ubica solo con `place_text` esquivando las caras detectadas.
- Hook de 3 a 7 palabras y caption con la plantilla de `clipardo-marca` (crédito "en vivo en", `#clipardo`).
